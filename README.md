## 🎯 Project Overview

This project demonstrates that **modern open-source AI tools**, when carefully orchestrated, can produce professional-quality multimodal podcast content with **zero manual intervention and zero budget**.

Every element of the final video was generated automatically:

| Element | Generated By |
|---------|-------------|
| 📝 Dialogue Script | Anthropic Claude (LLM) |
| 🔊 Two Distinct Voices | Piper TTS (VITS Neural Model) |
| 🖼️ Avatar Portraits | DALL-E 3 (Bing Image Creator) |
| 👄 Lip Synchronization | Wav2Lip GAN |
| 🎬 Final Video Assembly | ffmpeg + OpenCV |
| 📜 Subtitles | Auto-generated from manifest |

---

## ✨ Key Features

- 🤖 **Fully Automated** — Zero manual editing between any phase
- 💰 **Zero Budget** — 100% free and open-source tools only
- 🎭 **Two Distinct AI Characters** — Different voices, personalities, and visual styles
- 🗣️ **Realistic Lip-Sync** — GAN-based audio-driven facial animation
- 📺 **HD Output** — 1280×720 @ 25fps with burned-in subtitles
- 🔄 **Resume Support** — Each phase can be re-run without reprocessing previous phases
- 🖥️ **CPU Only** — No GPU required, runs on any standard laptop
- ✅ **Schema Validated** — Pydantic V2 enforces data contracts between phases

## 🏗️ Pipeline Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                    AI PODCAST PIPELINE                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │

│  │ PHASE 1  │ ─────────────────▶ │ PHASE 2  │                  │
│  │  Script  │                    │  Audio   │                  │

│                                       │ 12x .wav               │
│                                       ▼                        │
│  ┌──────────┐    3x .png         ┌──────────┐                  │
│  │ PHASE 3  │ ─────────────────▶ │ PHASE 4  │                  │
│  │ Visuals  │                    │ Lip-Sync │                  │
│  │ (DALL-E) │                    │(Wav2Lip) │                  │
│  └──────────┘                    └──────────┘                  │
│                                       │ 12x .mp4               │
│                                       ▼                        │
│                                  ┌──────────┐                  │
│                                  │ PHASE 5  │                  │
│                                  │ Assembly │ ──▶ 🎬 final.mp4 │
│                                  │ (ffmpeg) │                  │
│                                  └──────────┘                  │

```

Each phase produces a **JSON contract artifact** consumed by the next phase, ensuring full modularity and fault isolation.

## ⚙️ Installation

### Prerequisites
- Python 3.10+
- Git
- ffmpeg (added to PATH)

### 1 — Clone the Repository
```bash
git clone https://github.com/YourUsername/ai-podcast-pipeline.git
cd ai-podcast-pipeline
```

### 2 — Install Python Dependencies
```bash
pip install piper-tts soundfile numpy pydub librosa
pip install opencv-python torch torchvision
pip install pydantic python-dotenv tenacity
```

### 3 — Clone Wav2Lip
```bash
git clone https://github.com/Rudrabha/Wav2Lip.git
mkdir Wav2Lip\checkpoints
```

### 4 — Download Model Weights
Download `wav2lip_gan.pth` from:
> https://github.com/justinjohn0306/Wav2Lip/releases/download/models/wav2lip_gan.pth

Place it in `Wav2Lip/checkpoints/wav2lip_gan.pth`

### 5 — Download Voice Models
Create a `voices/` folder and download from HuggingFace:

| Character | Voice Model | Link |
|-----------|-------------|------|
| ARIA | `en_US-lessac-medium.onnx` + `.json` | [Download](https://huggingface.co/rhasspy/piper-voices/tree/main/en/en_US/lessac/medium) |
| MARCUS | `en_US-ryan-medium.onnx` + `.json` | [Download](https://huggingface.co/rhasspy/piper-voices/tree/main/en/en_US/ryan/medium) |

### 6 — Set Up API Key (Phase 1 only)
Create a `.env` file:
```ini
LLM_PROVIDER=anthropic
ANTHROPIC_API_KEY=your-key-here
ANTHROPIC_MODEL=claude-opus-4-6
```

## 🚀 How to Run

Run each phase in order:

```bash
# Phase 1 — Generate dialogue script
python phase1_dialogue_generation.py

# Phase 2 — Synthesize voices
python phase2_audio_generation.py

# Phase 3 — Generate images (manual step via Bing Image Creator)
# Save to outputs/visuals/aria_avatar.png
#          outputs/visuals/marcus_avatar.png
#          outputs/visuals/studio_background.png

# Phase 4 — Lip-sync animation (~12 min on CPU)
mkdir temp
python phase4_lipsync.py

# Phase 5 — Final video assembly
python phase5_assembly.py

# Check progress at any time
python check_progress.py
```

## 🔬 Phase Details

<details>
<summary><b>📝 Phase 1 — Dialogue Creation (LLM + Pydantic)</b></summary>

- Uses Anthropic Claude to generate a structured JSON dialogue
- Pydantic V2 validates the output against a strict schema
- Enforces: speaker alternation, word count ≥280, no forbidden topics
- Output: `dialogue.json` with 12 turns, emotion tags, and timing hints

**Key validations:**
```python
✓ Both speakers present (ARIA + MARCUS)
✓ Strict speaker alternation (no two consecutive same speaker)
✓ Total word count ≥ 280 words
✓ No political or religious content
✓ Duration estimated at 140 WPM baseline
```
</details>

<details>
<summary><b>🔊 Phase 2 — Audio Generation (Piper TTS)</b></summary>

- VITS acoustic model → HiFi-GAN vocoder pipeline
- Two distinct voices: female (lessac) and male (ryan)
- Post-processing: RMS normalization to -18 dBFS + 350ms silence padding
- Output: 12 `.wav` files + `audio_manifest.json` with precise timestamps

**Architecture:**
```
Text → Phonemizer → VITS (mel spectrogram) → HiFi-GAN → .wav (22050 Hz)
```
</details>

<details>
<summary><b>🖼️ Phase 3 — Visual Assets (DALL-E 3)</b></summary>

- 3 images generated via Bing Image Creator (free, no account needed)
- Prompts engineered for frontal face orientation (Wav2Lip compatibility)
- Requirements: ≥256×256px, neutral expression, soft lighting, no obstructions

</details>

<details>
<summary><b>👄 Phase 4 — Lip-Sync (Wav2Lip GAN)</b></summary>

- S3FD face detector locates bounding box in each frame
- Generator synthesizes mouth region from mel spectrogram windows (80 bins)
- SyncNet discriminator enforces audio-visual temporal synchrony
- 12 turns × ~60s each = ~12 minutes total on CPU

**Tensor flow:**
```
Audio (.wav) → Mel Spectrogram (80×T) → Chunked (80×16) → Generator
Face image  → Crop (96×96×6)         ─────────────────▶ Generator
                                                              ↓
                                               Synthesized mouth (96×96×3)
                                                              ↓
                                               Blended back → .mp4
```
</details>

<details>
<summary><b>🎬 Phase 5 — Video Assembly (ffmpeg + OpenCV)</b></summary>

- Compositing: active speaker (full brightness) + inactive (55% dimmed)
- MARCUS horizontally mirrored so both characters face each other
- Three-stage ffmpeg pipeline: video concat → audio concat → merge
- Subtitles generated from manifest (100% accurate) and burned in

**Layout:**
```
┌──────────────────────────────────────────────────────┐
│  [ARIA - active/dimmed]    [MARCUS - active/dimmed]  │
│       460×460px                   460×460px          │
│       (mirrored)                  (mirrored)         │
│                   STUDIO BACKGROUND                   │
│              [Subtitle text here]                    │
└──────────────────────────────────────────────────────┘
              1280 × 720 px  @  25 fps
```
</details>

## ⚠️ Challenges & Solutions

| Challenge | Root Cause | Solution |
|-----------|-----------|----------|
| Coqui TTS install failure | Missing C++ build tools on Windows | Switched to Piper TTS |
| Piper API version mismatch | `synthesize()` signature changed | Used `synthesize_wav(wave.Wave_write)` |
| Wav2Lip path doubling | subprocess `cwd` conflict | Changed `cwd` to project root |
| ffmpeg not found | Not in system PATH | Downloaded gyan.dev build + `setx /M` |
| `temp/result.avi` missing | Wav2Lip expected `temp/` relative to cwd | Created `temp/` in project root |
| PyTorch downgraded to 2.11 | `batch-face` dependency conflict | Reinstalled torch 2.4.1 via official URL |
| Empty WAV file | Piper wave channels not configured | Used `setchannels(1)` before synthesis |
| Subtitle path on Windows | Backslashes invalid in ffmpeg filter | Replaced `\` with `/` + escaped `:` |
